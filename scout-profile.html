Workspace Memberships ⓘ WORKSPACE ARCHITECTURE A professional can access multiple workspaces. Workspace types: • Organization Workspace • Individual Workspace A single UI can show both, but objects should be marked with workspace context where needed. Each workspace can contain: • Members • Projects / Groups • Managed athletes • Evaluations • Requests • Messages • Notes • Activity history

UnicAthlete Scouting CRM System

This page documents the proposed MVP system structure. It explains how the recruiter-facing scouting CRM connects athlete discovery, evaluation, communication, and pipeline management into one structured recruiting workflow.

Discover → Save Prospect → Evaluate → Contact → Track Progress → Decision

CRM Logic

Core recruiting statuses and scout actions that define the workflow logic.

Pipeline Statuses

New: Athlete saved to prospects.
Reviewing: Scout is evaluating athlete.
Contacted: Scout sent message or request.
Discussion: Athlete responded and communication is active.
Decision: Signed, rejected, or archived.

Main Scout Actions

Add athlete to prospects.
Watch athlete profile updates.
Evaluate and write private notes.
Request additional recruiting information.
Message athlete and manage follow-ups.
Compare athletes and archive completed pipelines.
This page is not intended to function as part of the recruiter CRM itself. It is a system overview document used to explain the MVP structure, page relationships, and recruiting workflow logic.
